# منصة شامه للعلوم

منصة تعليمية باسم المعلمة **أ/ شامه البقمي**: أنشطة تفاعلية تحلّها الطالبات من جوالاتهن، ونتائج تصل للمعلمة مباشرة، وعجلة للحصة مع بنك أسئلة نافس (151 سؤالًا).

## مكونات المنصة

| الملف | الوصف |
|---|---|
| `docs/index.html` | صفحة الطالبات: يخترن النشاط والفصل والاسم ثم يحللن الأسئلة ويرين درجتهن. |
| `docs/teacher.html` | لوحة المعلمة: إنشاء نشاط، أنشطتي، النتائج، عجلة الحصة، إعداداتي. |
| `docs/wheel.html` | عجلة الأسماء مع أسئلة نافس والنقاط والشهادات. |
| `docs/assets/nafs.js` | بنك أسئلة نافس — علوم الصف السادس. |
| `docs/g6/` | ألعاب الصف السادس: صفحة الألعاب، ورحلة الهواء والدم، وعالم تحت المجهر، وبمهاراتي أنافس. الطالبة تختار فصلها واسمها مرة واحدة، فتصل زيارتها ونتيجتها إلى المعلمة. |
| `docs/assets/student.js` | هوية الطالبة في الألعاب، وإرسال الزيارة والنتيجة إلى Google Sheet. |
| `apps-script/Code.gs` | الخادم: يحفظ الأسماء والأنشطة والإجابات في Google Sheet الخاص بالمعلمة. |

أسماء الطالبات **لا تُحفظ في هذا المستودع**؛ تُحفظ فقط في Google Sheet الخاص بالمعلمة.

## التركيب (مرة واحدة)

### 1) ربط Google Sheet
1. افتحي [Google Sheet جديد](https://sheets.new) وسمّيه «منصة شامه».
2. الإضافات (Extensions) ← Apps Script.
3. احذفي الموجود والصقي محتوى `apps-script/Code.gs` ← حفظ.
4. اختاري الدالة `setup` من القائمة ثم «تشغيل» (Run) ووافقي على الأذونات.
5. نشر (Deploy) ← نشر جديد (New deployment) ← النوع: تطبيق ويب (Web app).
   - التنفيذ باسم: أنا (Me)
   - من يمكنه الوصول: أي شخص (Anyone)
6. انسخي رابط تطبيق الويب (ينتهي بـ `/exec`).

### 2) تشغيل الموقع
1. في GitHub: Settings ← Pages.
2. Source: Deploy from a branch ← Branch: `platform` ← Folder: `/docs` ← Save.
3. بعد دقيقة يصبح الموقع على: `https://shamahscience.github.io/Scienceshamah/`

### 3) أول دخول
1. افتحي `https://shamahscience.github.io/Scienceshamah/teacher.html`
2. الصقي رابط Apps Script، والرمز السري الأول `1234` (غيّريه من «إعداداتي»).
3. أضيفي أسماء الفصلين من «إعداداتي».
4. أنشئي نشاطًا، ثم اعرضي الباركود للطالبات.

## ملاحظة عند تعديل Code.gs
بعد أي تعديل على الخادم: نشر (Deploy) ← إدارة عمليات النشر (Manage deployments) ← تعديل ← إصدار جديد (New version) ← نشر، حتى يبقى الرابط نفسه.

## ألعاب الصف السادس والمتابعة
- رابط الطالبات: `https://shamahscience.github.io/Scienceshamah/g6/` (أو من لوحة المعلمة ← «ألعاب السادس والزيارات» ← الرابط والباركود).
- تُحفظ في Google Sheet ورقتان جديدتان: `games` (النتائج) و`visits` (الزيارات).
- بعد تحديث `Code.gs` يلزم نشر **إصدار جديد** (انظري الملاحظة أعلاه).
- لتقصير الرابط وتثبيت الباركود: الصقي رابط `/exec` في `CONFIG_API` داخل `docs/assets/common.js` و`docs/assets/student.js`.
