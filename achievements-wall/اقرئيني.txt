حائط إنجازات الطالبات — طريقة التشغيل
==========================================

الفكرة
------
صفحة واحدة (index.html) تفتحها الطالبة من جوالها عبر رابط أو رمز QR،
بدون أي تسجيل دخول، فتضيف اسمها وفصلها وصورة إنجازها ووصفه.
يظهر الإنجاز على الحائط بعد اعتماد المعلمة، ويستطيع الجميع تشجيعه 👏.
المعلمة تدخل بحساب Google لتعتمد المشاركات أو تحذفها أو تميّزها 📌.

قبل الإعداد تعمل الصفحة في "وضع تجريبي": يمكنك تجربتها، لكن المشاركات تُحفظ
على الجهاز نفسه فقط ولا تصل للآخرين.

الإعداد مرة واحدة (حوالي ١٠ دقائق، مجاني)
-----------------------------------------
1) ادخلي https://console.firebase.google.com بحساب Google واضغطي "Create a project".
   (يمكنك إيقاف Google Analytics، لا حاجة له.)
2) من القائمة: Build ← Firestore Database ← Create database
   اختاري موقعًا قريبًا (مثل europe-west أو me-central) ثم "Start in production mode".
3) من تبويب Rules في Firestore: احذفي الموجود، والصقي محتوى ملف firestore.rules
   بعد تغيير "teacher@example.com" إلى بريدك، ثم Publish.
4) من القائمة: Build ← Authentication ← Get started ← Google ← Enable ← Save.
5) من ترس الإعدادات ⚙ ← Project settings ← Your apps ← أيقونة الويب </>
   سجّلي تطبيقًا بأي اسم، فيظهر لك كود فيه firebaseConfig = { apiKey: ... }.
6) افتحي index.html بأي محرر نصوص، وفي أعلاه استبدلي:
       const FIREBASE_CONFIG = null;
   بـ:
       const FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", ... };
   (انسخي القوسين { } وما بينهما كما هي من Firebase)
   وغيّري TEACHER_EMAIL إلى بريدك نفسه، وعدّلي قائمة CLASSES بأسماء فصولك.

النشر ليفتح للطالبات مباشرة
---------------------------
- إن كان المستودع منشورًا على GitHub Pages فالرابط سيكون:
      https://<اسم-الحساب>.github.io/<اسم-المستودع>/achievements-wall/
  ثم أضيفي هذا النطاق (<اسم-الحساب>.github.io) في Firebase:
  Authentication ← Settings ← Authorized domains ← Add domain
  (حتى يعمل زر "دخول المعلمة").
- اضغطي زر "رمز QR للطالبات" في الصفحة واعرضيه على السبورة أو اطبعيه.

ملاحظات
-------
- الصور تُصغَّر تلقائيًا قبل الرفع، فتكفي الخطة المجانية لمئات المشاركات.
- للفيديوهات والملفات الكبيرة: تضع الطالبة رابطًا (Drive أو YouTube) في خانة الرابط.
- لا تظهر أي مشاركة للطالبات قبل اعتمادك، وهذا محمي في قواعد الأمان وليس في الصفحة فقط.
